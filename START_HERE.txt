PC FINDER — START HERE

1) เปิดโฟลเดอร์นี้ใน VS Code
2) เปิด Terminal และเช็กว่าบรรทัด path อยู่ในโฟลเดอร์ที่มี package.json
3) รัน:

   npm install
   npm run dev

Mock เปิดไว้แล้วใน .env:
VITE_USE_MOCK_AUTH=true

จึงลองหน้า Login ได้โดยยังไม่ต้องมี Backend

Production build:
   npm run build
